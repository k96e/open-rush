# open-rush · 统一模型路由网关（llm-router）开发文档集

给**上下文有限的 LLM Agent**用的分层文档。全套约 53k token，但**任何一个任务只需要加载 8–15k**。

**基线**：`kanyun-rush/open-rush` @ `e62f507c37603cb7df40d87b5b4ee94a285503c7`

---

## 怎么用

```
每次开工
  └─ 1. 读 00-必读.md                （1.9k，每次都读，不要跳）
     2. 读 01-进度.md                （1.8k，看做到哪了、有没有阻塞）
     3. 打开当前阶段的 tasks/Mx-*.md  （阶段必读 + 该阶段全部任务卡）
     4. 按阶段文件顶部「本阶段要带上的备查文件」按需加载 ref/
     5. 收工：回填 01-进度.md
```

**只有 `01-进度.md` 可写**，其余全是只读参考。要改方向：先在 `01-进度.md` 的「决策变更记录」写清楚，再改 `ref/R2` 与 `specs/llm-router.md`，最后才动代码。

## 分层结构

```
open-rush-llm-router/
├── README.md              ← 你在这里（索引 + 上下文预算）
├── 00-必读.md             ← 【全局必读】每次开工都读
├── 01-进度.md             ← 【状态】唯一可写文件
├── tasks/                 ← 【阶段必读 + 任务卡】按 M0–M7 分
│   └── Mx-*.md
└── ref/                   ← 【备查】按需加载，不要一次性全读
    ├── R0–R8              ← 论证、模型、契约、验收、风险
    └── code/C1–C8         ← 代码骨架，按关注点拆
```
