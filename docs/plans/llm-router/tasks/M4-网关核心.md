## 本阶段目标

把网关跑起来：认证 → 路由 → 转发 → 旁路计量。做完这一阶段，Claude Code 就能把 `ANTHROPIC_BASE_URL` 指过来正常跑完一次对话。

**这是全项目风险最高、测试最该写扎实的阶段**——A1（零改写）与 A10（失败隔离）都在这里定生死。

## 本阶段的硬约束（既定决策，不要自行改动方向）

- **A1 的三档承诺**（见 R2 §3.1）：`passthrough` 承诺逐字节一致；`rewrite-model` 只允许改 `$.model` 一个字段；`translate` 不承诺字节一致。不要含糊地说"尽量不改写"。
- **请求头走开放列表，不做白名单过滤**。`anthropic-beta` 的取值集合随 Claude Code 版本增长，过滤会在新版本发布时静默打断新能力。
- **上游错误体原样透传，不得包一层信封**。Claude Code 的能力降级重试按上游错误文案匹配，包装会破坏恢复路径。
- 路由**按 path 匹配**：Claude Code 实际请求的是 `/v1/messages?beta=true`。

## 易踩坑

- **先 `controller.enqueue(chunk)` 再 `observe(chunk)`**，顺序反了会把旁路解析的耗时算进 TTFB。
- `enqueue` 传的必须是**同一个 `Uint8Array` 引用**——不拷贝、不改写、不重新分块。单测要断言对象引用相同。
- 向上游发 `accept-encoding: identity`，避免解压/再压导致下游字节不一致。
- `TextDecoder` 解析时必须带 `{stream:true}`，否则跨 chunk 的多字节 UTF-8 会被截断。
- `message_delta.usage` 是**累计值**，多个 delta 之间取 `max` 而不是相加。
- **必须实现 `HEAD /api/hello`**（Claude Code 的连接预热探针），否则日志刷 404。
- `/v1/models` 要在 **3 秒内同步返回且不重定向**（含 http→https），否则模型发现静默失败。
- 502 的错误体里**不能出现 baseUrl**，只说供应商的 name。

## 阶段完成判定

- [ ] 假上游联调：`cmp` 请求与响应字节一致
- [ ] `sse-tee` 单测：随机分块 × N 组，字节一致 + chunk 引用一致 + cancel 触发 onEnd
- [ ] 一个从未见过的 `anthropic-beta` 值能原样到达上游（证明没做白名单）
- [ ] 上游 500 + 自定义错误体 → 状态码与 body 原样透传
- [ ] 全绿门禁通过

#### T4.1 `apps/llm-router` 骨架
- **产出**：app 骨架、`server.ts`（见 C7 §7.14）、`/healthz` `/readyz` `HEAD /api/hello`、`.env.example`
- **要点**：`package.json` 照抄 `apps/agent-worker`（tsup + tsx + hono + @hono/node-server）；根 `pnpm-workspace.yaml` 已含 `apps/*`，无需改
- **验收**：`server.test.ts`：healthz 200；catalog 未加载时 readyz 503；HEAD /api/hello 200；私钥缺失时 `main()` 退出非 0
- **依赖**：T2.2, T3.2

#### T4.2 令牌认证
- **产出**：`src/auth/{router-token.ts,token-store.ts,drizzle-token-store.ts}`（见 C5 §7.12）；`apps/llm-router/src/middleware/authenticate.ts`
- **验收**：无头 → 401；非 `rt_` 前缀 → 401；已吊销 → 401；已过期 → 401；`x-api-key` 形式也能认；缓存命中不打 DB；`invalidate()` 生效
- **依赖**：T1.1, T4.1

#### T4.3 `forward` + `headers`
- **产出**：`src/proxy/{forward.ts,headers.ts,model-rewrite.ts}`（见 C4 §7.8–7.10）
- **验收**（用本地起一个 fake upstream，**不打真供应商**）：
  - `buildUpstreamHeaders`：剥 hop-by-hop、剥 `authorization`/`x-api-key`、保 `anthropic-version`/`anthropic-beta`、**未知 `anthropic-*` 头默认放行**、三种 authStyle 各注入正确的头、`accept-encoding: identity`
  - `stripHopByHop`：上游若回显 `authorization` 也被剥掉
  - `rewriteModelField`：**深度相等断言**（除 `model` 外）
  - 上游 500 + 自定义错误体 → 状态码与 body **原样透传**
  - 上游连不上 → 502，且响应体**不含 baseUrl、不含任何密钥**
- **依赖**：T2.1, T3.3, T4.2

#### T4.4 `sse-tee` + usage 解析
- **产出**：`src/proxy/sse-tee.ts`（见 C2 §7.3）、`src/usage/{types.ts,anthropic-parser.ts,openai-parser.ts,cost.ts}`（见 C2 §7.4/7.5）
- **验收**（**这是 A1/A5 的核心测试，务必写扎实**）：
  - 用真实形状的 SSE 固定装置（fixture），随机切成 N 组不同边界的 chunk：断言**下游拼接结果与上游逐字节一致**，且 chunk 数量与对象引用相同
  - 跨 chunk 的多字节 UTF-8 字符不被截断（`TextDecoder({stream:true})`）
  - `message_delta` 累计语义：多个 delta 取 max，不叠加
  - 只有 `message_start` 没有 `message_delta` 时也能出数
  - 畸形 JSON / `[DONE]` / `event:` 行 / 注释行 不影响解析与转发
  - `onChunk` 抛错时流仍完整（旁路隔离）
  - 客户端提前 cancel → `onEnd(reason)` 被调用一次
  - `computeCostUsd`：五类 token 各自计价、零价、缺字段
- **依赖**：T4.1

#### T4.5 `/v1/messages` + `/v1/messages/count_tokens` + `/v1/models`
- **产出**：`apps/llm-router/src/routes/{messages,count-tokens,models}.ts`
- **要点**：
  - 路由匹配**按 path**，`/v1/messages?beta=true` 必须命中
  - `stream` 字段决定走流式还是缓冲分支
  - `/v1/models` 返回 `{ data: [{ id, display_name }] }`，**同步返回、不重定向、控制在 3 秒内**
- **验收**：happy path、未知 alias → 404、无令牌 → 401、令牌不允许该 alias → 403、body 非法 JSON → 400、缺 `model` → 400
- **依赖**：T4.3, T4.4
